# rules 후처리 흐름 예시 풀이

- 날짜: 2026-09-23
- 브랜치: `fix/name-seal`
- 워크트리: `.worktrees/name-seal`

`backend/rules.py`가 VLM 추출 결과를 어떻게 다듬고, AO 결과의 이상을 어떻게 찾아 고치는지 예시 입력으로 따라간다. 아래 출력은 모두 실제 실행 결과다(재현 스크립트는 맨 아래).

## 전체 흐름

```
VLM 원본 ─▶ [apply] 정규화 → 쓰레기 값 버림 → OCR 근거로 빈칸 채움
                     → 표 정리 → 관례 파생 ─▶ Docraft 결과
                                                  │
AO 결과 ─────────────────────────────────▶ [check] 이상 징후 찾기
                                                  │
                                           [correct] 확실한 것만 룰로 수정
                                                  │
                                    남은 이상 + AO≠Docraft 필드 ─▶ Judge(LLM) 판정
```

호출 위치는 `verify.run`이다. `apply`는 채점(`scripts/verify_eval.py`)에서도 쓰고, `derive`는 라벨 정리(`scripts/verify_label.conform`)에서도 쓴다. 추론·채점·라벨이 같은 규칙을 공유한다.

### `apply` 단계 순서

| # | 함수 | 하는 일 |
|---|---|---|
| 1 | `_value` | kind별 정규화 → `_junk`로 라벨·HTML 잔재 제거 → `FIELD_RULES` 정제 → enum 동의어 매핑 |
| 2 | `_fill` | 빈 스칼라를 `LABELS` 동의어로 블록에서 찾아 채움(근거 등급·영역·배타 필터, 값이 하나로 모일 때만) |
| 3 | `_notes` | 소견 문장·`날짜 (검사)` 표시로 치료·검사·수술 내역 행 생성 |
| 4 | `_split_codes` | 병명 칸의 KCD 코드 분리 |
| 5 | `_receipt_table` | 진료비영수증 항목 행을 파서 표로 복원·보충 |
| 6 | `_totals` | 합계행 금액으로 빈 합계 필드 채움 |
| 7 | `_group_titles` | 묶음 제목 열(급여·비급여) 비움 |
| 8 | `_period` | 진료기간을 표 시작·종료일자로 채움 |
| 9 | `derive` | 표 열 관례, 주민번호 → 성별·생년월일, 외래/입원, 사고발생일자 |
| 10 | `_master_names` | 코드가 마스터에 있을 때만 명칭 1글자 오인식 교정 |

## 예시 A. 진단서 — `apply`

입력 ① VLM 원본

```json
{"이름": "홍길동 (인)", "환자 주민번호": "900101-1234567", "성별": "성별",
 "진단일": "2026. 9. 1", "발급일": "2026년 09월 05일",
 "병원명": "명칭: 서울정형외과의원(직인)", "진료과": null,
 "병명내역": [{"병명": "요추 염좌 (S33.5)", "병명코드": null}]}
```

입력 ② OCR 파서 블록

```
표:  | 환자 | 성명 | 홍길동 |  /  | 진료과목 | 정형외과 |
텍스트: "치료소견: 요추부 통증으로 물리치료 및 약물치료 시행함"
        "2026.09.03 (검사)"
```

| 단계 | 필드 | 전 | 후 | 이유 |
|---|---|---|---|---|
| ① 정규화 | 진단일 | `2026. 9. 1` | `20260901` | date → YYYYMMDD |
| | 발급일 | `2026년 09월 05일` | `20260905` | 표기가 달라도 같은 형식 |
| | 병원명 | `명칭: 서울정형외과의원(직인)` | `서울정형외과의원` | `_hospital`이 라벨·직인 제거 |
| | 이름 | `홍길동 (인)` | `홍길동` | `_name`이 도장 표시 제거(이번 수정) |
| | 성별 | `성별` | `null` | `_junk`: 값 자리에 라벨 글자 → 버림 |
| ② `_fill` | 진료과 | `null` | `정형외과` | 표의 `진료과목` 셀(동의어, 등급 0) 오른쪽 값 |
| ③ `_notes` | 치료내역 | — | `[{치료명: "요추부 통증으로…시행함"}]` | `치료소견:` 뒤 10자 이상 문장. 날짜는 과거력일 수 있어 비움 |
| | 검사내역 | — | `[{검사일: 20260903, 검사명: 검사}]` | `날짜 (검사)` 표시 |
| ④ `_split_codes` | 병명내역 | `요추 염좌 (S33.5)` | 병명 `요추 염좌`, 코드 `S335` | 코드 분리(비교용 정규형이라 점 제거) |
| ⑨ `derive` | 성별 | `null` | `남` | 주민번호 뒷자리 첫 숫자 `1` |
| | 생년월일 | — | `19900101` | `1` → 1900년대 + `900101` |

①에서 라벨 글자 "성별"을 버렸기 때문에 ⑨에서 주민번호로 올바른 값이 채워진다. "틀린 값보다 빈칸이 낫고, 빈칸은 근거가 있으면 채운다"는 설계가 이렇게 맞물린다.

## 예시 B. 진료비영수증 — `check` → `correct`

- AO: 진찰료·검사료·합계 3행, `급여` 열에 15000·35000·50000
- Docraft: 4행, AO에 없는 `주사료`(금액 전부 0) 행 포함
- 블록 머리글: `| 항목 | 요양급여 |` / `| 항목 | 본인부담금 | 공단부담금 | 전액본인부담 |` — `요양급여`는 하위 열을 묶는 제목일 뿐이다

`check` 결과:

```
no_column    | 이 표에는 독립된 '급여' 열이 없으므로 0행 '진찰료'의 급여는 0이어야 한다. (1·2행도 같음)
row_missing  | Docraft가 읽은 항목 '주사료' 행이 AO 표에 없다.
sum_mismatch | 진료비총액 50,000이 합계 행의 본인부담금+…+급여 100,000과 다르다.
```

세 신호가 같은 원인을 가리킨다. AO가 제목 열에 소계를 넣어 금액이 두 번 세어졌고(50,000 → 100,000), 주사료 행을 빠뜨렸다.

`correct` 결과:

```
row_missing: 금액이 모두 0인 '주사료' 행을 Docraft에서 채웠다
진찰료 | 본인 5000  | 공단 10000 | 급여 15000
주사료 | 본인 0     | 공단 0          ← Docraft 순서대로 진찰료 뒤
검사료 | 본인 15000 | 공단 20000 | 급여 35000
합계   | 본인 20000 | 공단 30000 | 급여 50000
```

| 이상 | 룰 교정 | 이유 |
|---|---|---|
| `row_missing` 주사료 | 고침 | 금액이 전부 0이라 끼워도 잃을 것이 없다 |
| `no_column` 급여 | 안 고침 | Docraft도 같은 금액을 `비급여`로 읽었을 때만 옮긴다. 이번엔 근거가 없다 |
| `sum_mismatch` | 안 고침 | 교정 규칙이 없고 신호만 준다 |

교정 뒤 `check`를 다시 돌려 남은 `no_column`·`sum_mismatch`는 `항목내역`의 hint 문장으로 disputes에 붙어 Judge가 이미지와 함께 판정한다.

## 원칙

근거가 확실할 때만 고치고, 애매하면 비우거나 Judge에게 넘긴다.

## 찾은 버그와 수정

예시 A를 돌리는 중 `이름: "홍길동 (인)"`이 `"홍길동인"`이 되는 것을 발견했다. `_name`은 한글 외 글자만 지우고 `_NAME_WORDS`에 도장 표시 `인`이 없어서 남았다. 이름 안의 `인`(김인수·이인)은 지키고, 괄호 속 `(인)`·`[인]`·`(印)`과 이름 뒤에 떨어진 `인` 토큰만 도장 표시로 지우도록 고쳤다. 회귀 테스트를 추가했다.

## 재현 스크립트

```python
from backend import rules
vlm = {"이름": "홍길동 (인)", "환자 주민번호": "900101-1234567", "성별": "성별",
       "진단일": "2026. 9. 1", "발급일": "2026년 09월 05일", "병원명": "명칭: 서울정형외과의원(직인)",
       "진료과": None, "병명내역": [{"병명": "요추 염좌 (S33.5)", "병명코드": None}]}
blocks = [{"rows": [["환자", "성명", "홍길동"], ["진료과목", "정형외과"]],
           "text": "치료소견: 요추부 통증으로 물리치료 및 약물치료 시행함\n2026.09.03 (검사)"}]
print(rules.apply("진단서", vlm, blocks))

ao = {"진료비총액": "50000", "공단부담총액": "30000", "환자부담총액": "20000",
      "항목내역": [{"항목": "진찰료", "본인부담금": "5000", "공단부담금": "10000", "급여": "15000"},
                  {"항목": "검사료", "본인부담금": "15000", "공단부담금": "20000", "급여": "35000"},
                  {"항목": "합계", "본인부담금": "20000", "공단부담금": "30000", "급여": "50000"}]}
docraft = {**ao, "항목내역": [{"항목": "진찰료", "본인부담금": "5000", "공단부담금": "10000"},
                             {"항목": "주사료", "본인부담금": "0", "공단부담금": "0"},
                             {"항목": "검사료", "본인부담금": "15000", "공단부담금": "20000"},
                             {"항목": "합계", "본인부담금": "20000", "공단부담금": "30000"}]}
blocks = [{"rows": [["항목", "요양급여", "", ""], ["항목", "본인부담금", "공단부담금", "전액본인부담"]]}]
checks = rules.check("진료비영수증", ao, docraft, blocks)
print(checks, rules.correct("진료비영수증", checks, ao, docraft))
```
