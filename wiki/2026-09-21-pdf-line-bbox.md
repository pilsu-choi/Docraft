# PDF 근거 상자 정밀화

- 기존 PyMuPDF 텍스트 **블록** bbox는 여러 줄을 한꺼번에 포함해 빨간 상자가 사진·문서의 큰 영역을 덮을 수 있었다.
- PDF 파서를 텍스트 **줄** 단위로 바꿨다. 각 줄의 실제 bbox와 페이지 크기를 같은 PDF 페이지 좌표(포인트, 좌상단 원점)로 저장한다. 이미지 블록은 텍스트로 취급하지 않는다. 줄의 순서는 유지하고 Markdown에서는 줄바꿈 하나로 연결한다.
- 합성 2줄 PDF에서 줄별 bbox·텍스트 순서·Markdown을 검증했다. 기존 로컬 PDF 2개를 내용 출력 없이 좌표 크기만 점검하니 가장 큰 bbox 높이 비율이 각각 12%→3%, 38%→9%로 줄었다.
- **기존 저장 문서의 블록·근거는 자동 변경하지 않는다.** 새 좌표를 적용하려면 해당 문서에서 ‘다시 분석하기’를 실행해야 한다. 이 작업은 DB나 사용자 파일을 수정하지 않았다.
