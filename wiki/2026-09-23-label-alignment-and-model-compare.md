### 2.9 해석 — 재실행 변동을 감안하면

같은 모델·같은 프롬프트로 영수증을 재실행했을 때의 변동 폭이 **existing 기준 ±43셀**이라는 실측이 있다([extract-grounding](2026-09-22-extract-grounding.md)). 이 잡음을 기준으로 보면:

- **잡음 범위 안**: existing 전체 −13셀, existing 영수증 +12셀, existing 세부내역서 −17셀. → existing 36건에서는 두 모델의 정확도 차이를 **없다고 봐야 한다.** 새 모델이 existing 영수증에서 97.7% vs 97.2%로 앞선 것도 우세의 근거로 쓸 수 없다.
- **잡음 범위 밖**: holdout 전체 −212셀, 그중 holdout 영수증 −58셀·holdout 세부내역서 −146셀. → 실제 하락이다. 다만 세부내역서 −146은 문서 1건(−155)이 전부이고(§2.5), 영수증 −58은 항목 행 누락이라는 한 가지 실패 유형에 몰려 있다(§2.4 ②).
- **방향이 일관된 지표**: strict는 전체 7,764→7,411(−353)로 잡음보다 훨씬 크게 떨어졌고, existing만 봐도 3,709→3,726으로 개선이 아주 작다. 반대로 fp는 330→321, 소견서에서 14→4로 분명히 줄었다.

정리하면 **새 모델은 "환각은 덜 하지만 표를 덜 정확하게·덜 빠짐없이 읽는다"**. 이 벤치마크의 대부분이 표 문서(영수증 4,479셀 + 세부내역서 4,189셀 = 전체의 94%)라 총점은 새 모델이 진다.

### 2.10 권고 (결정은 사용자 보류)

현 벤치마크(76건, 최종 라벨, rules 단계) 기준으로 새 모델은 **정확도 −2.4%p(strict −3.8%p) · 지연 약 1.5~3배 · 단가 입력 1.9배·출력 3.75배**로 세 축 모두 이전 모델보다 불리하다. 전환을 정당화할 별도 사유(컨텍스트 262k, 특정 서식 대응, 공급 안정성 등)가 없다면 **`qwen/qwen3-vl-32b-instruct` 유지**를 권고한다.

다만 이는 권고일 뿐이고, **모델 전환 여부 결정은 사용자에게 보류한다.** 판단을 뒤집을 수 있는 요소는 두 가지다 — (a) 세부내역서 하락의 대부분이 문서 1건의 행 밀림이므로 그 실패가 프롬프트·표 복원으로 고쳐지면 격차가 −225셀에서 −70셀 수준으로 줄어든다, (b) 환각(fp) 억제가 중요한 용도라면 새 모델이 유리하다.
