# UI 개편 제안 및 진행 상태

## 요청

사용자는 현재 화면이 복잡하고 시각적으로 아쉽다고 평가했으며, 더 트렌디하면서도 단순하고 직관적인 UI를 원한다.

## 적용한 방향

- 따뜻한 중립 배경, 선명한 흰색 작업 면, 짙은 글자색과 한 가지 녹색 강조색을 사용하는 절제된 SaaS 스타일을 제안한다. 장식용 일러스트와 중복된 카드·버튼은 줄이고 간격·서체·상태 표현을 일관되게 정리한다.
- 시작 화면은 프로젝트 생성과 파일 업로드를 하나의 명확한 주요 행동으로 묶고, 최근 프로젝트는 간결하게 보여준다. 프로젝트 목록은 이름·상태를 먼저 읽게 하고 이름 변경·삭제는 보조 행동으로 둔다.
- 작업 화면은 **문서 파싱 → 스키마 생성·편집 → 추출·검토** 순서를 명확히 드러낸다. 각 단계에는 다음 행동 하나를 우선 배치하고, 현재 문서·처리 상태·참조 원문을 항상 쉽게 확인할 수 있게 한다.
- 프로젝트/스키마 CRUD, 파싱 완료 문서 기반 자동 스키마, 실제 근거 위치의 빨간 bbox, 원문·작업 패널 접기/펼치기 기능은 유지한다. 기존 E2E 테스트가 찾는 주요 접근성 이름과 선택자도 보존한다.

사용자가 즉시 구현을 요청해 외부 Superdesign 인증을 기다리지 않고 위 방향을 화면에 적용했다. 외부 디자인 서비스나 폰트 요청은 사용하지 않았다. 홈/프로젝트 목록/작업공간의 정보 위계, 여백, 카드·버튼, 색과 상태 표시를 통일하고 작업 단계는 번호가 있는 한글 탭으로 바꿨다. 프로젝트·스키마 CRUD와 추출·검토 기능은 그대로 유지했다.

PDF·이미지 미리보기의 크기·클리핑 수정은 별도 버그 수정으로 진행 중이며 회귀 테스트 중이다. 이번 UI 작업은 `main.tsx`, `styles.css`, `panels.css`만 수정했다. 프런트엔드 빌드가 통과했고, 브라우저 레이아웃 검증을 후속 진행한다.
