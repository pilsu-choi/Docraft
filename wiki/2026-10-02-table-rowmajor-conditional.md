## 1. 요약

| | asis(현행) | rowmajor | 조건부 rowmajor |

| 세부내역서 정확도 | 80.90% | 79.53% | **81.07%** (감지 시 asis 재추출) |
| 진료비영수증 정확도 | 99.62% (오류 23칸) | 99.39% (37칸) | **99.61% (24칸)** (양식별 열 배치) |

두 방식을 합치면 정확도는 asis와 같거나 조금 높습니다. 영수증 13칸이 개선돼 전체 약 89.7%(추정, 합쳐서 채점하지는 않음)이고, 지연은 절반 수준입니다. 2단계 통과 기준(정확도 손실 0.1%p 이하, 지연 40% 이상 감소)을 충족합니다.

## 2. 열 밀림 감지 (`ab/gate_ab.py`, LLM 호출 없음)

- 신호: rowmajor 결과에 Docraft `rules._row_arith`를 돌려, 총액이 있는 행 가운데 산식(단가×투여량×횟수×일수=총액, 본인+공단(+전액)=총액)이 맞지 않는 행의 비율을 계산합니다. 감지 조건은 rowmajor 출력만 보고 판단합니다.
- 조건: 세부내역서에서 이 비율이 0.3 이상이면 asis로 다시 읽습니다. 걸린 문서는 2건입니다.
  - 열이 밀린 문서: 신호 0.714, 다시 읽어 37.8% → 68.4%
  - `SA2020010684193`: 신호 0.333, 79.5% → 87.7%
  - 잘못 감지한 문서는 0건입니다.
- 영수증 합계 검사(열 합계와 합계 행 비교)는 쓰지 않습니다. 합계가 안 맞는 영수증은 asis에서도 대부분 안 맞기 때문입니다. 이 검사로는 다시 읽을 필요 없는 문서만 잡혀 지연이 늘어납니다.
- 한계: 열이 밀린 실제 사례가 1건뿐입니다. 0.333 문서가 기준선 바로 위에 있어서, 0.2와 0.3 중 무엇이 나은지 판단할 근거가 적습니다.

## 3. 영수증 양식별 열 배치 (`ab/receipt_layout.py`, OpenRouter 30회)

- 근거 문서: `harness-v2/docs/requirements/진료비영수증_양식별_스키마/`. 양식 5종의 금액 열 구성과 항목내역 설명이 들어 있습니다.
- 양식 판별: OCR 머리글의 낱말로 판별합니다. `요양급여(①+②)`이면 1, `선택진료료 외·이외`가 있고 선택진료료도 있으면 4, 선택진료료가 없으면 5, `본인부담` 열이면 2입니다.
  - 30건 중 29건을 판별했고 잘못 판별한 문서는 0건입니다.
  - 분포는 양식 1이 2건, 2가 5건, 4가 22건이고, 판별하지 못한 문서가 1건입니다. 이 1건은 OCR이 '이외'를 놓친 경우로, 8열 통합 스키마로 읽습니다.
  - 표본에 양식 3·5가 없어 두 양식은 검증하지 못했습니다.
- 호출: 판별한 양식에 인쇄된 금액 열만, 인쇄된 순서대로 rowmajor에 줍니다. 받은 값은 Docraft 통합 열로 되돌리고, 없는 열은 0으로 채웁니다.
- 결과
  - 정확도 99.39% → 99.61%, 열 뒤바뀜 2칸 → 0칸
  - p50 18.7 → 14.4초, 출력 토큰 1,121 → 871
- 나빠진 문서: `선택진료료외만_금액표기`(오류 2칸 → 5칸, 선택진료료외 값 3칸이 비었고 원인은 찾지 못함). `소계포함`은 스펙에 없는 소계 열 때문에 개선되지 않았습니다.
- 주의: 이 실험에서는 열 배치와 함께 열 설명도 양식별 스키마의 문구로 바꿨습니다. 그래서 개선 효과를 두 요인 중 어느 쪽 덕분인지 나눠 볼 수 없습니다.

## 4. 다음 단계 (3단계: Docraft 반영)

1. Docraft에 표 추출 방식 설정을 추가합니다(예: `TABLE_EXTRACT=asis|rowmajor`, 기본값 asis). 적용 위치는 `verify.py`·`reprocess.py`의 `engine.extract` 호출부입니다.
2. rowmajor일 때
   - 세부내역서는 `_row_arith` 실패 비율이 0.3 이상이면 asis로 다시 읽습니다.
   - 영수증은 양식을 판별하면 그 양식의 열만 주고, 판별하지 못하면 통합 스키마로 읽습니다.
3. 오프라인 59건을 다시 돌려 확인한 뒤 dev에 반영하고, AWS 확인은 배포 담당 세션(6c)을 통해 합니다.
4. 남은 확인 사항: 양식 3·5 표본 확보, `선택진료료외만_금액표기`에서 값이 빈 원인.
