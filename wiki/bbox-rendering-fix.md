# 원문 근거 상자 표시 수정

2026-09-21

- 원인: 뷰어가 네 좌표 모두 1 이하인 상자를 무조건 정규화 좌표로 해석했다. PDF 파서와 추출 근거의 좌표는 페이지 포인트 단위의 절대 좌표이므로, 원점 근처의 작은 PDF 상자가 화면의 큰 비율로 늘어날 수 있었다. 기존 상자는 반투명 붉은 채움도 사용해 큰 영역이 점이나 얼룩처럼 보였다. 전역 버튼 스타일은 원인이 아니다. 상자는 `span`이다.
- 수정: PDF 상자는 항상 PDF 페이지 크기를 기준으로 절대 좌표 변환한다. 이미지 상자는 명시적인 `page_size`가 있으면 절대 좌표로, 크기 정보가 없는 0–1 범위 근거는 정규화 좌표로 해석한다. 일반·선택 상자 모두 채움 없는 붉은 직사각형 외곽선으로 표시하고 선택 상자는 선 두께만 강조한다. 둥근 모서리·최소 크기·패딩 없이 실제 좌표 폭과 높이를 유지한다.
- 검증: 합성 PDF와 3000×4500 이미지의 일반·0.3 단위 미세 상자를 모킹 API로 표시하고 `getBoundingClientRect`를 예상 픽셀 좌표와 비교했다. PDF 근거(`page_size` 없는 절대 좌표), 가상 이미지 정규화 근거(현재 운영 OCR은 이미지 bbox를 반환하지 않음), DPR 2, 확대·축소, 패널 리사이즈와 모바일 화면까지 `tests/ui_preview_layout.py`에서 확인했다. 실제 프로젝트나 AI 서비스는 사용하지 않았다.
- 참고: 과거 PDF 파서가 만든 큰 텍스트 블록 상자는 프런트만 변경해도 크기가 줄지 않는다. 새 파서는 줄 단위 상자를 만들지만 저장된 문서는 명시적으로 다시 분석해야 새 좌표를 얻는다.
