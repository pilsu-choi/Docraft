# 프로젝트 작업공간 개편

## 최종 사용자 요구

- 홈 메뉴는 `새 프로젝트`, `프로젝트 목록` 두 개로 제한한다.
- 프로젝트 목록에서 생성·조회·수정·삭제하고 프로젝트를 클릭하면 상세 화면으로 이동한다.
- 참고 UI는 원본 저장소의 `refs/landingai/` 이미지 6개다.
- 데이터베이스는 Docker PostgreSQL로 전환한다.
- 스키마 자동 생성은 OCR·파싱이 완료된 결과를 입력으로 사용한다. 문서의 원본 형식은 이미지·PDF·Office·스프레드시트 등일 수 있다.
- 스키마 생성 프롬프트는 선택 입력이다. 생성된 스키마를 조회·추가·수정·삭제하고 선택한 스키마로 추출한다.
- 실제 bbox가 존재하면 원문 위에 빨간색 테두리로 표시한다. 페이지·크기·확대 비율에 맞게 위치를 변환하며 존재하지 않는 좌표를 만들지 않는다.
- 파싱을 우회하여 원본 이미지만으로 스키마를 생성하는 흐름은 사용자 정정에 따라 제외한다.
